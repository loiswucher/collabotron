# Collabotron

Séance autoguidée sur la justesse des transmissions (AS/IDE), 2 h 30, sur téléphone.

- Accueil : `index.html`
- Page de garde (plan + QR code) : l'adresse seule, ou `#/affiche`
- Aucune donnée n'est envoyée : les réponses restent sur le téléphone, les messages de la chaîne voyagent dans le QR code.
